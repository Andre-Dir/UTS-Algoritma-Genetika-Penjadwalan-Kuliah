# Checklist Kesesuaian UTS

- [x] 20 mata kuliah unik
- [x] 8 dosen pengampu
- [x] 5 ruang, kapasitas simulasi ditandai
- [x] 5 hari × 5 slot
- [x] Representasi kromosom `(hari, slot mulai, ruang)`
- [x] Fitness `1/(1+jumlah pelanggaran)`
- [x] Cek bentrok dosen, ruang, kelas, kapasitas
- [x] Inisialisasi populasi acak
- [x] Seleksi roulette dan tournament
- [x] Crossover one-point dan uniform
- [x] Mutasi acak
- [x] Elitisme
- [x] 10 run seed berbeda
- [x] Grafik fitness per generasi
- [x] Tabel jadwal dan ekspor CSV/Excel
- [x] GUI dashboard Streamlit sebagai tambahan (UTS tidak mewajibkan UI)
- [ ] Repositori GitHub kelompok + dosen sebagai kolaborator
- [ ] Laporan UTS 8–12 halaman, minimal 5 referensi penelitian serupa (ada dari paket tugas sebelumnya; sesuaikan hasil aplikasi)
- [ ] Presentasi 15 menit, demo langsung, tanya jawab individu
- [ ] Verifikasi data kapasitas dan kelas saat data sebenarnya tersedia

**Perhatian:** semua angka keberhasilan adalah validitas model simulasi, bukan jadwal resmi universitas. Percobaan harus diulangi apabila input dan parameter berubah.
